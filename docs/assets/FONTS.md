# Fonts in the README artwork

The wordmark and figures in `banner-*.svg`, `ledger-*.svg`, `cover.svg` and `social-preview.png`
are outlined glyphs (paths, not live text) taken from the fonts the website already ships in
`site/assets/fonts/`: **Archivo** (SIL Open Font License 1.1) and **Roboto** (Apache License
2.0). They are artwork, not linked code, and no font file is embedded in any SVG.
