Requirements and size

Android

Android 10 (API 29) or later. Android 9 is not supported.

Processor

arm64-v8a and x86_64. There is no 32-bit build.

Per architecture

About 48.5 MB to download.

Universal package

About 59.3 MB to download.

Optional packages use more space.

The Expert edition can fetch some packages only when requested. Beangrow's closure downloads 37 MB and occupies about 143 MB after unpacking.

Which edition should you use?

Play

Use it when you want store-managed updates and do not need native Python packages or the Android bridge from your own code.

Expert

Use it when your plugins need compatible native packages, on-demand packages, or Android APIs, and you are comfortable installing signed releases directly.

Files are identical between editions. A project created in one opens unchanged in the other and in desktop Beancount.
