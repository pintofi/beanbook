Features

Beancount, from entries to reports.

The accounting engine is upstream Beancount. The reporting surface is upstream Fava. The Android app makes both usable on a phone.

Entries and editing

Use guided entry for common work and raw text when the file is the clearest interface.

Guided entry

Use guided entry for common directives. Edit, delete, or duplicate existing entries while keeping the ledger as ordinary Beancount text.

Raw files

Read and edit the ledger files themselves with highlighting, search, validation, and stale-write detection.

Durable writes

Writes are locked, snapshotted, journalled, atomically replaced, and re-parsed before success is shown.

Unknown syntax survives

Unknown directives, metadata, comments, whitespace outside an edited region, includes, and relative paths are preserved.

Reports computed by Fava

Tier 1 opens the full Fava report surface. The free tier keeps the journal, account balances, and raw editor.

Documents, mirroring, and backup

The app keeps the private workspace canonical and provides explicit routes to portable copies.

Receipts and statements

Capture or attach documents, assemble PDFs, and file them against entries. Documents live inside the portable project tree.

Manual copies

Export to an ordinary folder or a backup archive. Manual import, export, backup, and restore are always free.

Auto-mirror

Tier 2 can keep a copy in a chosen SAF folder. Conflicts preserve both versions and wait for your decision.

Scheduled backup

Tier 2 can schedule backups with configurable retention. Optional passphrase encryption uses AES-256-GCM with Argon2id.

Remote mode is deliberately narrower

Remote mode is a hardened client for a Fava server you host. It provides reports and quick-add while the server is reachable.

It does not keep an offline copy, edit existing remote entries, or attempt two-way sync. An https:// certificate error is fatal. An http:// connection is used only when you type that scheme and is disclosed as unencrypted before connection.

Plugins and scripts

Tier 3 can load user-supplied Beancount plugins, Fava extensions, beangulp importers, and Python scripts.

Code you choose

User Python is unsandboxed and can access anything the app can. Loading is off by default, controlled per project, and disabled in safe mode.

Play edition

User extensions must be pure Python. The Android bridge is withheld, and the edition never downloads code.

Expert edition

User Python can use the Android bridge. Optional compatible packages can be fetched on demand after the app shows the closure.

Large packages stay optional

The beangrow dependency closure is a 37 MB download and occupies about 143 MB unpacked, so it is not bundled in every install.

Not a security boundary. Plugin restrictions in the Play edition are policy compliance. User Python is unsandboxed in both editions.

Check the edition before installing.

The ledger format is identical in both editions, but package and update behavior differs.
