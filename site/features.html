Features

From a shop receipt to a yearly summary.

Entering what you spent takes a few taps. Behind it is Beancount, the same double-entry accounting software people run on a desktop, with Fava's reports on top — both running on your phone.

Recording what you spend

A form for everyday entries, and the text file itself when that is quicker — both write to the same place.

Guided entry

Use guided entry for common directives. Edit, delete, or duplicate existing entries while keeping the ledger as ordinary Beancount text.

Raw files

Read and edit the ledger files themselves with highlighting, search, validation, and stale-write detection.

Durable writes

Writes are locked, snapshotted, journalled, atomically replaced, and re-parsed before success is shown.

Unknown syntax survives

Unknown directives, metadata, comments, whitespace outside an edited region, includes, and relative paths are preserved.

Where the money went

Documents, mirroring, and backup

The app keeps the private workspace canonical and provides explicit routes to portable copies.

Receipts and statements

Capture or attach documents, assemble PDFs, and file them against entries. Documents live inside the portable project tree.

Manual copies

Export to an ordinary folder or a backup archive. Manual import, export, backup, and restore are always free.

Auto-mirror

Auto-mirror keeps a copy in a folder you choose, such as one your cloud storage syncs. If the same file changes in both places, both versions are kept and you decide.

Scheduled backup

The app can back up on a schedule and keep as many past copies as you choose. A backup can be protected with a passphrase you set.

Remote mode is deliberately narrower

Remote mode is a hardened client for a Fava server you host. It provides reports and quick-add while the server is reachable.

It does not keep an offline copy, edit existing remote entries, or attempt two-way sync. An https:// certificate error is fatal. An http:// connection is used only when you type that scheme and is disclosed as unencrypted before connection.

Plugins and scripts

The app can load add-ons you supply: Beancount plugins, Fava extensions, importers for your bank's exports, and Python scripts. There is a list of add-ons people use.

Code you choose

An add-on runs with the app's permissions and can reach anything the app can: it is a program you are trusting. Add-ons are off until you turn them on, per project, and safe mode holds all of them back.

Play edition

Add-ons must be plain Python, cannot use your phone's own features, and this edition never downloads code.

Expert edition

Add-ons can use your phone's own features, and can fetch extra Python libraries on demand after the app shows what it would download.

Big libraries stay optional

Some add-ons need libraries far larger than the app itself, so they are never bundled. You are shown the download and its size before anything is fetched.

Not a safety guarantee. The Play edition's limits on add-ons are store rules, not protection for your ledger. In both editions an add-on runs with the app's permissions.

Check the edition before installing.

The ledger format is identical in both editions, but package and update behavior differs.
