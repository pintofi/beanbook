Privacy policy

Your ledger is not our data.

There is no account, sign-in, analytics, telemetry, crash reporting, advertising, or licence server.

Applies to both the Play and Expert editions. Last updated 4 September 2026.

Local mode makes zero network requests.

It works with the network off. The local Fava service binds only to 127.0.0.1 on an ephemeral port and requires a per-process token.

What the developer collects

Nothing. The app has no user accounts and no developer-operated service that receives your ledger, receipts, balances, contribution-key details, search history, or credentials.

There are no analytics, telemetry, crash-reporting, advertising, attribution, or tracking SDKs in either edition. Contribution keys are verified offline. There is no licence server and no phone-home check.

Data on the device

Ledger files, financial information, documents and receipt photos, in-app searches, contribution-key details, and remote credentials remain local unless you start a transfer described below.

Project data lives in app-private storage protected by Android's device encryption and device lock. Widgets can be set to show a label and a time but no figures, and Android hides widget contents on the lock screen regardless.

Remote credentials and tokens are stored through Android Keystore. Entitlement keys are excluded from logs, backups, screenshots, widget previews, and diagnostics.

When data leaves the device

The repository audit found three outbound code paths: the address entered for remote mode and, in the Expert edition only, optional package fetching and update checks. User-initiated sharing can also send a selected document to an app the user chooses.

Your Fava server

If you enter a remote Fava address, the app connects to that server. The configured origin is allowlisted exactly. External navigation requires confirmation and opens in the browser.

If the address uses https://, certificate errors are fatal and cannot be bypassed. The app never downgrades a failed HTTPS connection. If you explicitly type http://, the connection is unencrypted and can be read or modified on a hostile network, including credentials and entries. The app warns about this while the address is being entered.

Optional packages in Expert

The Expert edition can make network requests to fetch optional Python packages.

Expert update checks

Expert update checks never happen on their own: there is no background check, no automatic download and no automatic install. You ask for one. The Play edition has no self-update code.

Sharing a document

A document is shared only after the user chooses Share and selects another app. Android grants that app read access to the selected file rather than the project as a whole.

Diagnostics

Diagnostics remain on the device until the user chooses to share them. The bundle is redacted by default: it excludes ledger content, amounts, account names, credentials, contribution keys, and other secrets, and it is shown before sharing.

Permissions

  • Camera: requested at the point of use for receipt capture.
  • Internet: required even to open the local loopback socket used by on-device Fava, and used for the user-initiated network cases above.
  • Notifications: used for backup and script results.

The app requests no broad storage permission, location, contacts, or account access. User-selected files and folders are reached through Android's Storage Access Framework.

No account deletion process

There is no account to delete. The developer cannot delete local data that the developer never receives.

The cleartext case is not hidden.

An address beginning with http:// is a user decision for a LAN or VPN setup. It is not encrypted, inferred, or used as a fallback.
