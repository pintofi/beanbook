# Changelog

All notable changes to Beanbook. The format follows [Keep a Changelog](https://keepachangelog.com/).

## [Unreleased]

### Changed
- Each processor type (arm64-v8a, x86_64) has its own APK with its own version code, so F-Droid and the phone choose the matching one. The universal APK stays on the release page.

### Fixed
- The entry form no longer refuses an entry Beancount accepts: the balance check now follows Beancount's own per-currency tolerance rule, including `inferred_tolerance_default`.
- The project picker no longer fails after restoring a backup.
- A save that is interrupted by the screen closing is finished or put back, never left undecided; after a crash, a raw edit you typed is kept even if the engine is down at the next start.
- Undo after restoring a backup can no longer put the old project's files back over the restored ones, and Undo stays in order if the device clock is reset.
- A snapshot taken before a write is flushed to storage before the ledger is replaced, and a damaged one is never restored over an intact ledger.
- Checking a backup is bounded in memory, and a backup archive can no longer ask the app to spend gigabytes deriving its key.
- Files you named `key` are included in backups and the mirror.
- Diagnostics redact `Authorization: Bearer` tokens, cookies and whole passphrases, and no longer risk a crash when logged from several threads.
- A ledger cannot list another project's documents by naming a folder with a shared prefix.
- Typed lots accept thousands separators, as Beancount does.
- Editing a ledger with Windows (CRLF) line endings keeps its line endings instead of mixing them.
- A cached answer is no longer reused after a plugin changes or the app is updated.
- A failed engine start no longer makes every later read wait out its timeout.
- Displayed amounts round half to even, as Beancount and Fava do.
- A remote server address typed with capital letters no longer shows blank pages, and a server under a path prefix such as `/fava` is found correctly.
- A remote server that answers oddly (a hostile ledger name, an endless reply) ends in an error message instead of a crash or a stall.
- A link in a report opens in the browser only after you confirm it, and only if it is a web address.
- Deleting or editing an entry checks that the file still holds the entry you were looking at, instead of acting on a line number from an older list.
- Text typed in the file editor while a save is running is no longer lost.
- The report view recovers when Android closes it to free memory, instead of taking the app down.
- A plugin picked from a file manager cannot be named so that it lands outside the install folder.
- A failed backup says what it left behind and removes the unfinished file; copies of backups, imports and script output no longer stay in the app's cache.
- Saving a remote password recovers from an unusable Keystore key and reports a failure instead of crashing.
- The entry form refuses an amount it cannot read (such as `4,50` or `4.5O`) instead of leaving it out and letting Beancount fill in a figure.
- Deleting a selection that includes an entry generated by a plugin no longer removes the entry after it.
- The document scanner frees its image memory as it goes instead of waiting for the garbage collector.
- Restore cannot be started twice; removing fetched packages or a saved script asks first; a sharing user name can contain a space.

## [1.0.0] - 2026-10-15

### Added
- Scripts show their output live, can be cancelled, and no longer stop after 30 seconds.
- The Mirror page lists the last ten files and decisions.
- A README with animated artwork, screenshots, a social preview and store images.
- A Support row in About in the Expert edition, linking to Ko-fi.
- Units, At cost and Market value on Home, Balances and the widgets, matching Fava's switch.
- Journal filters for errors, pending and flagged entries.
- Add forms follow the ledger's plugins (`commodity_attr`, `leafonly`, `check_commodity`).
- Undo for a saved entry, a delete and a raw-editor save.
- Per-plugin load status and an extension-failure count.
- The Bound Ledger redesign on Material 3 Expressive, built for 200% text, landscape and tablets.

### Fixed
- Pages shared on Wi-Fi are read-only: a signed-in browser can no longer save through Fava's editor.
- Reports no longer flashes the browser error page when the local server is a moment late; the loading cover stays and the load is retried.
- The SciPy-free overlay for `fava_portfolio_returns` was missing from every build (Android drops asset folders starting with an underscore); it ships now.
- Entries are written followed by a blank line, and deleting one removes it, as Fava does.
- Saving an entry with a scanned page no longer crashes the app.
- Deleting an entry also removes the blank line that set it apart, so adding and deleting returns the file to how it was.
- Plugins installed before their Android overlay existed get it applied at start (the SciPy-free `fava_portfolio_returns`).
- Searching the Journal no longer crashes when two entries share a position.
- Native companion libraries are fetched for the device's own architecture.
- The mirror is per project, and Reports follow the open project.
- Filing a scan finishes by itself once the include line is added.
- A refused save names the errors it would add; accounts the ledger has not opened are refused.
- Widgets keep each project's figures.
