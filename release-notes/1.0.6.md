Beanbook 1.0.6 puts every filter in one sheet on Home, Journal and Balances, lets a backup carry your templates, plugins, scripts and preferences, and asks before it creates a file or a line in your ledger.

**Filters.** One Filters button opens one sheet with the period, text, tags and links, an amount, and an account, and it suggests account names as you type. A tag can be left out with `-#trip`, and the amount box takes comparisons such as `>=100` and `<50`.

**Backup.** Under Backup, "Also include app data" lists what can go in, grouped and ticked item by item: entry templates, plugins, saved scripts, preferences, the project colour and the remote server address. Passwords are never included. A restore shows what is new, what is already here and what would replace a setting, and brings back only what you tick. The catalogue plugins you had installed come back as a list with an Install again button in the Expert edition. A backup with app data can only be opened by this version or a later one.

**Safety.** A restored backup turns every plugin off until you turn it on. A new file or line in your ledger is made only after you approve it, and the entry form says when typed text is not something Beancount accepts.

**Fixes.** Account names with non-ASCII letters work in the entry form, Mirror lists a file again each time it is sent, and a saved script that disappears while the list is read no longer breaks the list. The document scanner uses OpenCV 5.1.0.
