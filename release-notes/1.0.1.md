Beanbook 1.0.1 shrinks the download and fixes what a full review of the code turned up.

**Smaller downloads.** Each processor type has its own APK, so a phone fetches only its own libraries: arm64-v8a is 78.6 MB, x86_64 is 111 MB, and the universal APK (148.6 MB) stays for sideloading on any device. Android and F-Droid pick the matching one.

**New**
- Deleted projects are listed in a Trash section on the Projects screen, with their size. Put them back or delete them for good.
- Receipt photos and attached copies are removed from the app's cache once the document is filed.

**Fixed**
- The entry form accepts every entry Beancount accepts, using its per-currency tolerance rule.
- A save interrupted by the screen closing is finished or put back, never left undecided.
- Unlinking a document no longer removes the link of a different document with the same file name.
- Undo after restoring a backup can no longer put the old project's files over the restored ones.
- Remote server addresses with capital letters or a path prefix such as `/fava` work.
- Plus many smaller fixes to backups, plugins, the report view and the editor. The changelog lists them all.

**Under the hood.** The bundled Python runtime is 3.13.16, and Gradle dependencies are now checked against recorded checksums.
