Beanbook 1.0.5 starts an import from the Beancount file you select, lets you rename a project and give it its own colour, asks before refusing a change that adds an error, and adds update checks for plugins and packages.

**Importing and mirror.** You select your Beancount file, whatever it is called, and only the files it links to come with it, in the same folders. The mirror covers exactly those files. Importing from a .zip or a whole folder is gone; restoring a backup is unchanged.

**Projects and appearance.** A project can be renamed, with Undo. Each project can take its colour from your wallpaper or from an accent of its own, and Appearance has higher contrast, larger figures, compact rows and a reduce-motion switch. Errors and notes appear in coloured boxes.

**Saving.** A change that would add an error to your ledger asks first: Don't save, or Save anyway, which Undo can take back. Share on Wi-Fi can allow editing, and Fava's editor now saves through the same checked write as the app.

**Expert edition.** Plugins and extra packages can be checked for newer versions, updated, and rolled back.
